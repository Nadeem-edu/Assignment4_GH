# Flask MongoDB Project
The TO-Do Task submission app is used to add details and push it to MongoDB Backend

# Sys Prerequisites
Python 3.10+
MongoDB Atlas Cluster

## Local Setup
1. Clone the Repo over SSH
2. Initialize a local python virtual env
3. Install dependencies - '''pip install -r requirements.txt'''
4. .env file at the root dir and Map you Mongo_URI
5. Launch the app - '''python app.py '''
